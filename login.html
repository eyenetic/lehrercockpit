Datenschutz

Das Lehrercockpit ist ein privat betriebener Dienst für die Lehrkräfte eurer Schule.

Wo deine Daten liegen

  • Nur auf deinen Geräten: Klassenlisten, Einsammlungen, eigene Links und Einstellungen. Damit sie auf einem neuen Gerät wieder da sind, liegt eine Kopie verschlüsselt auf dem Server – der Schlüssel entsteht nur in deinem Browser aus deinem Zugangscode; der Server kann sie nicht lesen.
  • Auf dem Server, verschlüsselt: Links und Zugänge zu WebUntis, itslearning und Nextcloud – das Cockpit braucht sie, um deinen Stundenplan und deine Termine abzurufen.
  • Auf dem Server: Name, E-Mail (falls angegeben), deine Klassenauswahl für Hinweise und Rückmeldungen an die Verwaltung.

Zugangscode

Dein Code wird nur als Argon2id-Hash gespeichert – niemand kann ihn auslesen, auch die Verwaltung nicht.

Bitte nicht eingeben

Keine personenbezogenen Daten von Schülerinnen und Schülern (Namen mit Noten o. Ä.).

Weitergabe

Keine Weitergabe an Dritte, kein Tracking, keine Werbung. Der optionale KI-Assistent schickt nur Plan- und Termindaten an die Claude API von Anthropic – und nur, wenn du ihn einschaltest.
